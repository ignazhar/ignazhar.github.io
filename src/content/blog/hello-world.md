This is my new site. Every post is a single Markdown file, and the file name
becomes the URL — this one is `hello-world.md`, so it lives at `/blog/hello-world/`.

## Photos

Paste a photo straight into Obsidian and it lands in `images/`, then shows up here,
automatically resized and compressed:

![A calm lake](images/Pasted%20image%2020261118101500.png)

## Everything else

Normal Markdown works: **bold**, *italic*, [links](https://astro.build),
lists, quotes, tables and code.

> Write first, fiddle with the design later.
